# 研究方法语义表（Research Method Semantics）

> 目的：保证全站不同页面对同一术语使用一致定义。任何新页面引用这些概念时必须与本文一致；修改定义需同时更新相关页面。
> 格式：中文为主，英文术语括号保留。

---

## 一、感知与状态

| 术语 | 本站定义 | 易混淆点 |
|---|---|---|
| **失败检测**（Failure Detection） | 判断"是否发生了失败"（二分类 / 异常检测） | 不回答是哪种失败 |
| **失败诊断**（Failure Diagnosis） | 判断"是哪种失败"（在失败假设集合上区分） | 包含检测，不止于检测 |
| **失败假设**（Failure Hypothesis） | 预定义的可区分失败类别（成功 / 错位 / 卡滞 / 滑移 / 接触丢失 / 未知失败），来自 researchProfile 配置，不硬编码 | 不是临时分类标签 |
| **（后验）信念**（Belief） | 在失败假设集合上的（后验）概率分布；是"证据更新后的判断"，不是单点预测置信度 | ≠ 置信度（单值）；不译"信仰 / 信任状态" |
| **置信度**（Confidence） | 模型对单个预测的自我报告确定性 | ≠ 校准 |
| **校准**（Calibration） | 预测置信度与经验正确率的吻合程度（如期望校准误差 ECE 度量） | 校准好 ≠ 准确率高 |

## 二、可诊断性与主动诊断

| 术语 | 本站定义 | 备注 |
|---|---|---|
| **可诊断性 / 失败假设可辨识性**（Diagnosability） | 在可用观测下，失败假设能否被区分的系统属性（理论性质，非分数）。本课题主要用"失败假设可辨识性" | 动作条件化（action-conditioned）：加入候选动作后的可区分性 |
| **主动诊断**（Active Diagnosis） | 主动选择观测 / 探测动作以提升假设可区分性 | 理论近亲：主动故障诊断（Active Fault Diagnosis, AFD）、辅助信号设计 |
| **信息增益**（Information Gain, IG） | 一次观测对信念熵的期望降低量 | 不含代价；期望信息增益 = EIG |
| **信息价值 / 净信息价值**（Value of Information, VOI / NetVOI） | 信息收益 − 获取代价。本站 NetVOI = 预期决策风险降低 − 接触力风险 − 二次损伤风险 − 时间代价 − 任务进度损失（**启发式估计，非校准概率**） | 页面必须标注"启发式估计" |
| **暂缓判断**（Abstain / Abstention） | 明确的决策状态："当前证据不足以行动，且（可能）不值得继续探测" | 不译"弃权"。系统必须支持"不知道，但不值得继续探索"（失败假设实验室 NetVOI ≤ 阈值） |

## 三、恢复与安全

| 术语 | 本站定义 | 备注 |
|---|---|---|
| **恢复**（Recovery） | 从失败状态回到任务轨道的动作序列 | 本站主张基于失败后验的条件化恢复（belief-conditioned） |
| **安全回退**（Fallback） | 恢复失败后退回的安全行为（停止、回撤、释放） | 与恢复是两层 |
| **安全**（Safety） | 力 / 力矩硬限制优先；CBF / 无源性（passivity）在需要时叠加 | 执行层 = 阻抗 / 导纳；安全层只过滤不决策 |
| **撞题**（Collision，研究语境） | 论文与研究主线在模态 / 问题 / 状态 / 动作 / 恢复 / 理论上的重合 | 只用于选题重合语境；真实机器人碰撞才用"碰撞"（如碰撞次数 Collision Count） |

## 四、证据与结论规则（全站）

1. **研究主张**（Claim）：一个可被证据支持或反驳的明确陈述。
2. **证据**（Evidence）：指向具体论文 / 章节的引用，不允许无来源断言。
3. **最相近论文 / 最强反例**（Closest Paper / Strongest Counterexample）：结论卡片尽量同时显示最近支持与最强反例。
4. **判断可信度**（Confidence）：0–100 启发式研究决策辅助，页面必须标注：
   > 该评分用于研究决策辅助，不代表正式的文献计量或创新性证明。
5. **文献核验状态**（Verification Level）：已发现（DISCOVERED）→ 元数据已核验（METADATA_VERIFIED）→ 摘要已核验（ABSTRACT_VERIFIED）→ 全文已核验（FULLTEXT_VERIFIED）→ 正文与补充材料均已核验（SUPPLEMENT_VERIFIED）；未核验的显示"仅元数据"，不得冒充已核验。
6. **"雷达没找到" ≠ "没人研究"**：搜索覆盖不等于学术现实；研究缺口状态不用"已证明为空白"这类绝对语言。
7. **AI 输出**：必须标注"AI 生成的研究假设，需要人工核验"，且永不覆盖人工确认数据。
8. **证据充分性**（Evidence Sufficiency）：操作性决策变量，**不是**独立的新理论概念；通过可诊断性、后验分离度、信息价值、风险或停止准则等已有理论计算和解释。
